# 按键避障行走测试（switch_walk）

基于 `Test/template` 复制的四足行走测试工程，步态沿用 `Test/ble_walk_test`：

- 按一次 **S1（K1 = PB3）**，机械狗持续前进；
- VL53L0X 激光测距检测到**前方 10cm 内**有障碍时立即停止；
- 停止后不会自动恢复，必须**再按一次 S1**（且障碍已移开）才会继续前进。

> 机械结构改动：头部旋转了 180°，原来的“前进”变成了现在的“后退”，
> 左右方向不变。所以本工程的前进方向宏与 `ble_walk_test` 相反
> （`GAIT_FORWARD_SIGN = +1`，`ble_walk_test` 为 `-1`）。
>
> 方向反过来以后，抬腿顺序也必须跟着反过来（见“相位表”）。只改方向宏
> 不改相位表，等于用“倒着走”的序列往前走，机身俯仰和横滚耦合，会走偏、
> 严重时原地踏步。本工程已按新方向重新排相位。

## 操作

| 操作 | 结果 | 串口输出 |
| ---- | ---- | -------- |
| 按 S1，前方无障碍 | 开始前进，LED0 点亮 | `S1: walk forward` |
| 前进中前方 ≤10cm 出现障碍 | 立即停止，四腿平滑回中位，LED0 熄灭 | `STOP: obstacle within 10cm` |
| 障碍移开（≥13cm） | 保持停止，等待再次按键 | `CLEAR: press S1 to walk` |
| 障碍未移开时按 S1 | 不启动 | `BLOCKED: obstacle within 10cm` |
| 首次测距完成前按 S1 | 不启动 | `WAIT: TOF not ready` |
| 前进中重复按 S1 | 不打断步态，继续前进 | — |
| 连续 3 次测量失败 | 按障碍处理，立即停止（失效安全） | `STOP: TOF measurement error` |

上电串口输出（USART3，115200 8N1）：

```
[SWITCH WALK] S1 = walk forward, stop within 10cm
VL53L0X ready.
TOF: 235 mm
```

`TOF: xxx mm` 每 500ms 打印一次；超出量程时打印 `TOF: out of range`。

## 功能

| 功能 | 描述 |
| ---- | ---- |
| 按键行走 | S1（PB3，下拉输入、高电平有效）每按一次置为前进；20ms 消抖 |
| 非阻塞测距 | VL53L0X 每 100ms 启动一次单次测量，状态机轮询，不阻塞步态 |
| 障碍停车 | 距离 ≤10cm 立即停止；≥13cm 才解除（10~13cm 回差防抖） |
| 失效安全 | 首次有效测距前禁止启动；连续 3 次测量失败按障碍停车 |
| 状态指示 | LED0 行走时点亮（低电平点亮），停止熄灭 |
| 串口日志 | 状态变化与距离输出到 USART3，便于调试 |

## 步态说明

四条腿各 1 个舵机（TIM1 CH1~CH4），腿绕水平轴前后摆，中位 90° 竖直向下。
单舵机腿没有抬脚关节，靠**支撑相 / 摆动相的时间不对称**产生净位移：

- 支撑相（占周期 75%）：脚缓慢划动，接地时间长、地面冲量大；
- 摆动相（占周期 25%）：脚快速回摆，接地时间短、反向冲量小。

四条腿错开 1/4 周期（爬行步态），任意时刻只有一条腿在摆动，
另外三条支撑，机身不会跳。**抬腿顺序：1 → 3 → 2 → 4**（舵机编号，
对应新前进方向的 左后 → 左前 → 右后 → 右前，即同侧后腿先抬、前腿后抬）。

| 项目 | 默认值 | 说明 |
| ---- | ------ | ---- |
| 中位 | 90° | 腿竖直向下（可按腿加零位补偿） |
| 前进摆角 | ±23.0° | 由 `GAIT_STRIDE_MM = 36mm` 和腿长 46mm 算出 |
| 周期 | 800ms | 一个完整步态周期（原 600ms） |
| 支撑相 | 75%（600ms） | 支撑慢、摆动快 |
| 摆动相 | 25%（200ms） | 46° 回摆约 230°/s，普通舵机带载能跟上 |
| 更新周期 | 20ms | 每 20ms 更新一次 PWM |
| 限速 | 基础 8°/tick | 切换状态时平滑过渡；摆动更快时固件自动上调 |

> 周期放慢是这次修“原地踏步”的主要手段：600ms 时摆动相只有 150ms，
> 46° 回摆需要 300°/s 以上，舵机带载跟不上就会被拖成和支撑相一样慢，
> 占空比退化成 50%，地面冲量互相抵消。800ms 时摆动相 200ms，
> 只需要约 230°/s，能比较完整地还原 75/25 的不对称。
> 如果实物更慢，可继续加到 1000ms；走稳后嫌慢再逐步改回 600ms。

### 相位表（按新前进方向重新排）

腿编号沿用舵机通道：**1=PA8（原左前）、2=PA9（原右前）、
3=PA10（原左后）、4=PA11（原右后）**。头部转 180° 后，新前进方向的
前腿是物理上的 3/4 号，后腿是 1/2 号。四条腿错开 1/4 周期、支撑相 75%，
任意时刻只有一条腿在摆动：

| 腿（舵机） | 相位偏移 | 摆动窗口（全局相位） |
| ---------- | -------- | -------------------- |
| 1 原左前（新左后） | 750 | 0 ~ 249 |
| 2 原右前（新右后） | 250 | 500 ~ 749 |
| 3 原左后（新左前） | 500 | 250 ~ 499 |
| 4 原右后（新右前） | 0   | 750 ~ 999 |

按时间顺序即 1 → 3 → 2 → 4：新左后 → 新左前 → 新右后 → 新右前。
`ble_walk_test` 验证过的顺序是 3 → 1 → 4 → 2（旧方向的后腿先抬）；
头部转 180°、前进方向反过来后，本工程把四路相位整体反序，
等价于把已验证的步态按时间镜像，所以能保持原来的越障能力和直行性。

### 方向标定（头部旋转 180°）

`ble_walk_test` 的实测约定：**逻辑角减小 = 脚相对机身向前**，
其支撑相从 +1000 降到 -1000，所以前进取 `GAIT_FORWARD_SIGN = -1`，
让支撑相逻辑角增大、脚向后划、机身前进。

头部旋转 180° 后，新的“前进”就是原来的“后退”，所以本工程取：

```c
#define GAIT_FORWARD_SIGN  (+1)
```

如果实物上按 S1 后反而往后退，把该宏改回 `-1` 即可（只影响前后方向）。
左右转向本文测试未使用。**改方向宏时不要忘了同步检查相位表**：
前进方向反了，抬腿顺序也要反。

## VL53L0X 测距

驱动移植自 `Test/tof_test`（Pololu VL53L0X Arduino 库，HAL 阻塞式 I2C）。
与 `tof_test` 的区别是**测量过程改为非阻塞状态机**，不会卡住 20ms 的步态更新：

1. `TOF_STATE_IDLE`：上一次测量完成后再等 `TOF_MEASURE_MS`（100ms），
   调用 `TOF_StartSingle()` 启动下一次单次测量；
2. `TOF_STATE_WAIT_START`：每 5ms 读 `SYSRANGE_START`，等启动位自动清零；
3. `TOF_STATE_WAIT_READY`：每 5ms 读 `RESULT_INTERRUPT_STATUS`，
   就绪后读 `RESULT_RANGE_STATUS + 10` 得到距离并清中断；
4. 任一阶段 I2C 失败或超过 500ms 未完成 → 计一次错误，连续 3 次按障碍停车。

判定规则：

| 距离 | 处理 |
| ---- | ---- |
| ≤ 100mm | 有障碍，立即停止 |
| 100 ~ 130mm | 保持当前状态（回差，防止临界抖动） |
| ≥ 130mm | 无障碍；若之前有障碍则打印 `CLEAR`，但**不自动恢复行走** |
| > 2000mm / 8190 等 | 前方空旷，按无障碍处理 |
| 读寄存器失败 | 计一次错误；连续 3 次按障碍处理 |

单次测量约 33ms，加上 100ms 间隔，障碍判定延迟约 100~133ms。
按当前步态速度（36mm / 800ms ≈ 45mm/s）停车位置误差约 0.5~1cm。

## 可调参数（`USER CODE BEGIN PD`）

### 避障

| 宏 | 默认值 | 含义 |
| -- | ------ | ---- |
| `TOF_OBSTACLE_MM` | 100 | ≤ 该距离判定为障碍 |
| `TOF_CLEAR_MM` | 130 | ≥ 该距离才解除障碍（必须大于 `TOF_OBSTACLE_MM`） |
| `TOF_MEASURE_MS` | 100 | 两次测量的间隔 |
| `TOF_REPORT_MS` | 500 | 串口打印距离的间隔 |
| `TOF_ERROR_STOP_COUNT` | 3 | 连续测量失败多少次后按障碍停车 |
| `TOF_IO_TIMEOUT_MS` | 500 | 等待传感器内部完成的超时 |
| `KEY_DEBOUNCE_MS` | 20 | S1 消抖时间 |

### 步态 / 机械尺寸

| 宏 | 默认值 | 含义 |
| -- | ------ | ---- |
| `GAIT_FORWARD_SIGN` | +1 | 前进方向（头部转 180° 后）；走反了改 -1 |
| `BODY_WHEELBASE_MM` | 75.0 | 前后腿舵机轴距（mm） |
| `BODY_TRACK_MM` | 82.0 | 左右腿舵机轴距（mm） |
| `LEG_LENGTH_MM` | 46.0 | 舵机轴心到脚底的长度（mm） |
| `GAIT_CENTER_DEG` | 90 | 站立中位 |
| `GAIT_STRIDE_MM` | 36.0 | 每周期脚的前后行程（mm） |
| `GAIT_CYCLE_MS` | 800 | 步态周期（ms），越小走得越快，太小时舵机跟不上会拖步 |
| `GAIT_TICK_MS` | 20 | 步态更新周期（ms） |
| `GAIT_STANCE_PCT` | 75 | 支撑相占比（1~99），必须大于 50 才有净位移 |
| `GAIT_SLEW_DEG` | 8 | 每 tick 基础限速（°），摆动更快时自动上调 |
| `GAIT_MAX_TILT_DEG` | 30.0 | 单腿前后最大摆角（机械限位保护） |
| `GAIT_MIN_FOOT_GAP_MM` | 20.0 | 前后脚最小间距，限制最大步幅 |

### 直行标定（`USER CODE BEGIN PD`）

| 宏 | 默认值 | 含义 |
| -- | ------ | ---- |
| `GAIT_TRIM_1_DDEG` ~ `GAIT_TRIM_4_DDEG` | 0 | 每路零位补偿（0.1°），调四条腿站立竖直、左右对称 |
| `GAIT_YAW_TRIM_PCT` | 0 | 直行纠偏（%）：正数加大左侧步幅，负数加大右侧，范围 ±40 |

调法：

1. 把机器狗垫起（四脚离地）上电，看四条腿是否都竖直向下、前后是否
   在同一水平线。某条腿偏了，先调 `GAIT_TRIM_x_DDEG`（1 格 = 0.1°，
   先从 ±20 试），到四腿对称、中位一致。
2. 放到地面直行 1~2m：
   - 偏左（机头往左拐）→ `GAIT_YAW_TRIM_PCT` 加正数；
   - 偏右 → 加负数；
   - 每次 3~5%，直到基本走直。
3. 纠偏只在“脚能咬住地面”时有效。如果脚底明显打滑，先换防滑脚垫 /
   粗糙地面，再回来调。

安装方向数组在 `USER CODE BEGIN PV`：

| 数组 | 默认值 | 含义 |
| ---- | ------ | ---- |
| `s_servo_invert[]` | `{0,1,0,1}` | 反向安装标志，1 = 输出 `180-角度` |
| `s_phase_offset[]` | `{750,250,500,0}` | 爬行步态相位偏移（1~4 号舵机，按新前进方向重排） |
| `s_servo_trim_ddeg[]` | 全 0 | 每路零位补偿，来自上面的 `GAIT_TRIM_x_DDEG` |
| `s_servo_scale_pct[]` | `{100±trim,...}` | 左右步幅比例，来自 `GAIT_YAW_TRIM_PCT` |

## 常见问题

| 现象 | 排查 |
| ---- | ---- |
| 上电一直打印 `VL53L0X init failed` | 查 PC14 是否为高、PB8/PB9 接线与供电、I2C 上拉 |
| 按 S1 没反应，串口打印 `WAIT: TOF not ready` | 首次测距尚未完成（约 100ms 内），稍等再按 |
| 按 S1 不启动，打印 `BLOCKED` | 前方 10cm 内确实有障碍；移开后再按 |
| 按 S1 后往后退 | 结构换向后方向反了，把 `GAIT_FORWARD_SIGN` 改成 `-1` |
| 直行偏左 / 偏右 | 先按“直行标定”把四腿调竖直，再用 `GAIT_YAW_TRIM_PCT` 纠偏；地面打滑时纠偏效果会变差 |
| 原地踏步（腿在动但不前进） | 先确认 `GAIT_CYCLE_MS` 已放慢（800 起，不行加到 1000）；再确认脚底不打滑、四腿都着地；`GAIT_STANCE_PCT` 保持 75 以上 |
| 走起来一顿一顿 / 机身左右晃 | 周期太短、舵机带载跟不上；加大 `GAIT_CYCLE_MS`，或减小 `GAIT_STRIDE_MM` |
| 收到 `STOP` 但舵机缓慢回中 | 正常，限速 8°/tick 平滑回 90°，约 100ms |
| 距离一直 `out of range` | 目标超出量程或反射率太低；黑色/透明物体测不到 |
| 偶尔误停车 | 检查 TOF 安装角度是否照到地面/抖动；可加大 `TOF_ERROR_STOP_COUNT` |
| 前进中一顿一顿 | 串口打印过多或 I2C 读超时；确认模块接线稳定 |
| 完全不动、串口无输出 | 检查舵机 5V 与共地、TIM1 通道、USART3 115200 8N1 |
| 某条腿与其它腿方向相反 | 改 `s_servo_invert[]` 对应位（0/1 互换） |

## 验证建议

1. 上电后四腿回中位（90°），所有 LED 熄灭，串口打印提示与
   `VL53L0X ready.`，随后每 500ms 打印一次 `TOF: xxx mm`。
2. 手在 TOF 前方 5~30cm 移动，串口距离应随之变化；≥13cm 时按 S1，
   回包 `S1: walk forward`，LED0 点亮，四腿按 1→3→2→4 顺序依次摆动，
   机械狗持续前进。
3. 行走中把手放到 TOF 前方 10cm 内：约 150ms 内打印
   `STOP: obstacle within 10cm`，四腿平滑回中位，LED0 熄灭。
4. 保持障碍物不动再按 S1：打印 `BLOCKED`，不会启动。
5. 移开障碍物：打印 `CLEAR: press S1 to walk`，**仍保持停止**；
   再按一次 S1 才继续前进。
6. 用示波器测 PA8~PA11：行走时脉宽在 ~1244~1756us 之间非对称变化
   （支撑相约 600ms 慢变、摆动相约 200ms 快变）；停止后稳定在 1500us
   （若某路设了零位补偿，停止值会略偏离 1500us）。
7. 直行检查：在 1~2m 的直线上起步，观察是否持续前进、不原地踏步；
   若机头缓慢往一侧偏，按“直行标定”调 `GAIT_TRIM_x_DDEG` 与
   `GAIT_YAW_TRIM_PCT`，每次只改一个参数。
8. 拔掉 TOF 模块（保持运行）观察：连续 3 次测量失败后打印
   `STOP: TOF measurement error`，机械狗停止，不会“盲走”。

## 修改点（相对 template）

- `Core/Src/main.c`：
  - 沿用 `ble_walk_test` 的爬行步态，去掉转向，只保留前进/停止
  - 前进方向按头部旋转 180° 重新标定：`GAIT_FORWARD_SIGN = +1`
  - **相位表按新前进方向重排**（`{750,250,500,0}`），恢复“同侧后腿
    先抬、前腿后抬”的横向序列，修方向翻转后走偏/拖步
  - **步态周期 600ms → 800ms**，摆动相 200ms，舵机带载能跟上快摆，
    避免 75/25 占空比被拖成 50%（原地踏步）
  - **直行标定**：每路零位补偿 `GAIT_TRIM_x_DDEG` + 左右步幅比例
    `GAIT_YAW_TRIM_PCT`，用于校正机械安装误差造成的偏左/偏右
  - S1（PB3）消抖扫描，按一次启动前进
  - VL53L0X 驱动 + 非阻塞测距状态机（100ms 周期），10cm 障碍停车
  - 失效安全：首次测距前禁止启动，连续测量失败按障碍停车
  - 状态/距离串口输出，LED0 行走指示
- `Core/Src/usart.c`：使能 USART3 中断（NVIC，本工程只发不收）
- `Core/Src/stm32f1xx_it.c`：增加 `USART3_IRQHandler`
- 时钟/PWM 沿用模板：HSE 8MHz × PLL9 = 72MHz，TIM1 PSC=71、ARR=19999（50Hz）
- `MDK-ARM/CubeMX.uvoptx`：ST-Link 下载后自动复位运行
